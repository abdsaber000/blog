# Project: LibVLC Wayland API

Official project description: https://summerofcode.withgoogle.com/programs/2025/projects/uPnZ5zNu

## Description and Milestones Overview:

The goal of this project is to provide an API in libVLC that allows users to embed the media player in their applications. Although there is already support for X11 and the Windows API, Wayland behaves differently. By design, Wayland does not support embedding and does not notify when the surface size changes.

Initially, the plan was to use the `xdg-foreign` protocol to handle embedding through its export/import mechanism. However, it turned out that this protocol is not intended for such use.

Instead, embedding was achieved by assigning the video surface the role of a subsurface attached to the host application's surface, ensuring it has the same initial dimensions. Assigning the role of a subsurface creates a parent-child relationship between the host application and the video surface, which is necessary as it allows stacking the child relative to the parent, rendering the video from the top-left corner of the parent to the bottom-right, and moving it when the parent surface moves.

To handle resizing, the user must provide a callback function to the API. This function should be triggered on resize events, passing the new surface dimensions. The API also expects other callbacks, such as mouse press, mouse release, and mouse move, along with an opaque pointer to pass the host application's private data. If the user is not interested in supporting any of these callbacks, a `NULL` pointer should be passed instead.

The API was tested on popular Wayland compositors such as `GNOME Mutter`, `Sway`, `KWin`, and `Weston`. A demo application is also included to demonstrate how to use the API with Qt.

## How to Check The Work Done:

 1. Clone [repository](https://code.videolan.org/abdsaber000/vlc) and checkout to branch `wayland-test`.
 2. Compile and install libraries (it's recommended to follow the `contrib` method)
 3. Configure VLC compilation with some path for installation (`./configure --prefix=/path/to/install`)
 4. Compile  VLC and install it (`make install`)
 5. Include `libvlc` headers in your code to use the API.
 
 ## How to Run The Demo Application:
 
 1. Go to `doc/libvlc/QtWayland`.
 2. Create a new directory for building and navigate to it.
 3. Compile the demo program using the `cmake` script (`cmake .. -DVLC_INSTALL_PATH=/path/to/vlc/install && make`).
 4. Run the demo program with a path to media (`./vlc-wayland-player /path/to/media`).
